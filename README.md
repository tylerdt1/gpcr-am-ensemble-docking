# gpcr-am-ensemble-docking
Code and data accompanying "Benchmarking Docking Protocols for GPCR Allosteric Modulators" by Tyler D. Thompson and Yinglong Miao.

All docking scores, GaMD-derived structural ensembles, compound libraries, and analysis scripts used in this manuscript are available in this repository. GaMD simulation input files follow the protocols described in references [9] and [33]. CPPTRAJ clustering scripts used to derive structural ensembles are provided in the ensembles/ directory for each target.
