# gpcr-am-ensemble-docking
Code and data accompanying "Benchmarking Docking Protocols for GPCR Allosteric Modulators" by Tyler D. Thompson and Yinglong Miao.

All docking scores, GaMD-derived structural ensembles, compound libraries, and analysis scripts used in this manuscript are available in this repository. Clustering scripts used to derive structural ensembles are provided in the ensembles/ directory for each target. 

The example input files for GaMD equilibration and production simulations of GPCR allostery were provided in Supporting Information of Ref. 9. The GaMD simulation files for M2R, CCR2, and β2AR have been made publicly available at: https://doi.org/10.6084/m9.figshare.27327789 and https://doi.org/10.6084/m9.figshare.27390600. The GaMD simulation files for M4R have been made publicly available at: https://doi.org/10.6084/m9.figshare.33283491
