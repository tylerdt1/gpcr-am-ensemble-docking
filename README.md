# gpcr-am-ensemble-docking
Code and data accompanying "Benchmarking Docking Protocols for GPCR Allosteric Modulators" by Tyler D. Thompson and Yinglong Miao.

All docking scores, GaMD-derived structural ensembles, compound libraries, and analysis scripts used in this manuscript are available in this repository. GaMD simulation input files follow the protocols described in refs [9] and [33]. CPPTRAJ clustering scripts and allosteric pocket definitions used to derive structural ensembles are provided in the clustering/ directory for each target.
